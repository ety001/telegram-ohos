# telegram-ohos

鸿蒙 PC 原生 Telegram 客户端（个人自用，不上架应用市场）。

- 技术栈：ArkTS / ArkUI (API 26, PC-only) + TDLib (libtdjson) + NAPI 桥
- 目标设备：HarmonyOS 7 PC / 2in1
- 状态：🚧 规划完成，待开工（见 [docs/PLAN.md](docs/PLAN.md)）
